# 검증 범위와 한계

2026-10-24 / v0.5.0 실험판

## 확인한 사항

- Mac에서 단위·통합 시험, 종료·취소·자식 프로세스 파일 쓰기 중단.
- 스냅샷 식별, 변경·삭제 후 승인 무효화, 체크 파일 변조 차단.
- 완료 증거 누락·무진전·시간 제한·재개 시 마감 유지.
- 실제 Codex 0.162.1 가상 계산기 구현과 Claude Code 2.1.302의 별도 검토·감사 통과.
- 스킬 형식 검증과 기존 파일 덮어쓰기 거부.

## 미검증

- GitHub CI 자동 실행은 미활성화. 현재 인증의 workflow 권한이 없어 실행 설정 대신 CI_TESTS.example.yml에 예제를 보관한다. 저장소 소유자가 권한 있는 환경에서 .github/workflows/tests.yml로 추가하면 활성화할 수 있다.

- Windows 실제 실행. 사용자가 현재 불가하여 Mac 검증 범위로 우선 마무리하기로 함.
- 실제 1시간·4시간 연속 운전. 시간 경계는 짧은 대체 시간 및 결정 함수로 검사함.
- 악의적 프로젝트, CLI 전체 버전 조합, 회사 프록시·조직 정책.
- 정확한 과금 상한과 서비스 내부 기록 통제.

## 보안 및 동작 한계

JSON으로 선언한 신뢰된 파일만 다루며 기존 저장소 전체 수정은 지원하지 않는다. 검사 명령은 승인 입력이며 사용자 권한으로 실행된다. Codex workspace-write를 요청하지만 인증파일 읽기까지 완전히 차단하지는 못한다. Claude 도구·MCP는 끄고 스냅샷 내용을 입력으로 전달한다.

POSIX 프로세스 그룹을 이탈하는 악의적 자식은 격리하지 못한다. Windows는 Job Object에 부트스트랩을 할당한 후 명령을 시작·종료하나 실제 Windows 검증이 필요하다. 휴리스틱 키 탐지는 모든 비밀정보를 잡지 못한다.

정책·기록을 저장소 밖에 두고 해시를 비교하지만 같은 OS 사용자의 악의적인 기록 변조까지 막지 못한다. AI 의미 판단을 증명하지 않으며 독립 검토·감사와 검사 결과로 제한한다.

일시 오류도 자동 재시도 대신 중단한다. 비정상 종료는 잠금·활성 표시로 중복 실행을 차단하며 자동 복구하지 않는다. 구현 1시간 초과는 정리 후 미완료 코드를 검토하고 전체 마감 초과는 새 검토도 시작하지 않는다.

## 공개 범위

계정정보·토큰·원본 실행 로그·회사 데이터는 배포하지 않는다. 로컬 시험 결과도 원문을 GitHub에 올리지 않는다. 소스·가상 예제·테스트·문서만 제공하며 라이선스는 사용자 확정 전까지 미지정이다.
